# Project Manager

Role: Breaks work into small tasks, assigns owners, and keeps the build flowing in order.

Responsibilities:
- Create and maintain `docs/plan.md`.
- Sequence work by milestone: setup, movement, hero builder, World 1, power-ups, boss, quality gates.
- Coordinate the designer, art, gamedev, and QA handoff process.
- Track done checks and block status for each task.
